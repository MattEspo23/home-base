# Style the Home Base dashboard

Read `system/workflows/style-the-dashboard.md` from the Home Base root in full
and follow it.

Do the look the user asks for, confirm once, and pick the lightest place:
`instance/dashboard/theme.json`, then `theme.css`, then an instance module,
and the app itself only when nothing else can do it.
