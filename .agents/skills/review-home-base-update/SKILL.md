# Review a Home Base update

Read `system/workflows/review-an-update.md` and `system/UPDATE-GUIDE.md` from the Home Base root in full and follow them.

The explicit user request to review an update authorizes the workflow's bounded
public read-only discovery and verified download. Preview first, preserve
user-owned paths, and never apply without the exact reviewed approval.
