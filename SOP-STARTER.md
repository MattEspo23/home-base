# Find your first useful SOP

You do not need to know what an SOP is.

In Home Base, it simply means:

> A task you repeat enough that remembering the steps, decisions, and quality check would make the next run easier.

To find a good first one, say:

> Help me find a few things I repeat that might be worth turning into a skill.

The agent will ask about real work, one question at a time. It should look for:

- tasks that happen repeatedly;
- work that is slow, annoying, or easy to forget;
- handoffs where another person needs consistent instructions;
- tasks with important decisions or approval points;
- work where “done well” can be recognized.

It will recommend no more than three candidates and explain which one is the best place to start. If you choose one, it will use a recent real example to help draft the workflow.

It should never invent missing steps just to make the SOP look complete.
