# Support

Skill Vault is free, community-supported software. Support is best effort and
does not include a response-time or repair-time guarantee.

## Supported releases

- **Latest stable:** supported for documentation corrections and reproducible
  defects on a best-effort basis.
- **Preview or release candidate:** useful for testing, but may change or be
  withdrawn without migration support.
- **Older releases:** preserved as immutable history; upgrade to the latest
  stable before requesting a fix.

## Supported environments

- **Primary:** current Codex Desktop on a currently supported macOS release.
- **Preview:** Claude Code adapter. It remains best effort until a named live
  keeper run is recorded for the release.
- **Community/unverified:** other operating systems, agents, forks, and custom
  toolchains. Unverified does not mean known-broken.

Read the documentation and run `node scripts/validate.mjs` before reporting a
problem. Use the structured bug form for a reproducible defect. Once GitHub
Discussions is separately enabled for this repository, use Discussions for
questions and workflow ideas.

Never post credentials, client data, proprietary repository contents, private
prompts, or unredacted diagnostic output. Use [`SECURITY.md`](./SECURITY.md)
for sensitive reports.

Personalized setup, account recovery, connector/vendor support, and managed
implementation are not included in community support. They may be offered
separately under their own scope and terms.
