# Tools

This directory records what tools are relevant and how a possible connection should be bounded.

- `INDEX.md` — tools and proposed connection plans
- one Markdown file per reviewed connection purpose

A tool mentioned in conversation is not connected. A connection plan is not authorization. Never store passwords, tokens, recovery codes, or private keys here.

Prefer the smallest access that can produce the outcome: manual import, then one-time access, then read-only access, then narrowly scoped writes.
