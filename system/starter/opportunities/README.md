# Opportunities

Home Base uses this directory to show a small set of evidence-linked AI systems
the user may build.

- [AI-OPPORTUNITY-MAP.md](AI-OPPORTUNITY-MAP.md) — current map
- [INDEX.md](INDEX.md) — current, saved, declined, and superseded maps

A map may contain up to two actionable-now choices and one clearly saved-later
possibility. The user may choose one, ask to refine, or say none fit.
