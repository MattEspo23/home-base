# Work

This directory holds durable work or business context that applies across
projects.

- [BUSINESS.md](BUSINESS.md) — what the work is and how it creates value
- [PEOPLE.md](PEOPLE.md) — roles, collaborators, customers, and boundaries
- [PRIORITIES.md](PRIORITIES.md) — current outcomes and tradeoffs
- [CURRENT-TOOLS.md](CURRENT-TOOLS.md) — tools already used, without secrets

Keep one-project details in `projects/`. Keep connection authority in `tools/`
and chosen system authority in `systems/`.
