# Deepen Home Base

Use this workflow when the user asks Home Base to get to know them better.

## Choose one useful area

Offer a short choice based on the current gaps:

- responsibilities and current work;
- goals and priorities;
- people and relationships relevant to the work;
- tools and where information lives;
- trusted knowledge and source material;
- repeated tasks and SOPs;
- communication and working preferences;
- boundaries, approvals, and things to avoid.

Recommend the one most likely to improve an active project. Let the user choose.

## Interview

- Ask one question at a time.
- Ask no more than five questions before pausing to summarize.
- Build on existing files instead of re-asking known facts.
- When a new answer conflicts with durable context, show the conflict.
- Separate a standing truth from something that applies only to one project.
- Never request passwords, keys, private records, or unnecessary personal detail.

## Confirm and promote

After the short interview:

1. summarize new or changed understanding;
2. show the exact durable changes you recommend;
3. name where each change belongs and why;
4. ask for corrections;
5. update only confirmed information and its indexes;
6. identify one way the new context improves current work.

If the user is not ready to confirm a candidate, put it in `inbox/LEARNING-CANDIDATES.md` as `unconfirmed` rather than treating it as truth.

## Stop

End after one area unless the user asks to continue. A useful Home Base grows through many normal conversations, not one exhaustive interview.
