# Ideas

This directory holds optional Home Base suggestions.

- [INBOX.md](INBOX.md) — candidates that have not been accepted or declined
- [REVIEWED.md](REVIEWED.md) — accepted, declined, reopened, or retired ideas
- [SUGGESTION-LOG.md](SUGGESTION-LOG.md) — visible per-session budget

Ordinary work receives at most one unsolicited suggestion per active session.
An explicit opportunity review uses the separate three-or-fewer map contract.
