# Home Base version

- Version: `1.2.0`
- Status: public stable release
- Updated: 2026-10-21

## Version-one support

- Codex project instructions and built-in skill shortcuts
- Claude Code project instructions and built-in skill shortcuts
- Portable Markdown personal/work context, memory, knowledge, projects,
  opportunities, generated systems, capabilities, ideas, and user-created
  skills
- Progressive personal, work/business, or combined discovery
- Evidence-linked Opportunity Map with choose, refine, and “none fit”
- Complete system blueprints and four supported execution shapes
- Explicit Build Mode, credential refusal, consequence-led previews, stop
  gates, proof, and rollback
- Conversation-versus-interface decisions and a reversible local/private UI
  reference
- Visible suggestion budgeting, durable decline, and two-run learning proof
- Conversation-first SOP discovery, skill building, safe connection planning,
  update review, and learning closeout
- A pinned 42-Skill bundle (15 Home Base core + 27 released Skill Vault 0.1.3 packages)
  with matching Codex and Claude adapters, file hashes, and exact provenance
- Root MIT licensing, byte-verbatim third-party notices, protected brand/identity
  boundaries, latest-stable best-effort support, and private security routing
- Pristine starter packaging plus a three-way, customization-preserving update
  transaction with exact approval, conflict review, crash recovery, explicit
  deletion approval, checkpoint verification, and rollback
- A read-only Capability Doctor that distinguishes workflows, commands,
  plugins, connectors, authentication, permissions, and safe next steps
- Beginner installation guidance and a durable preference read in the
  executable two-run learning reference

## Added in 1.1.0

- A private `instance/` folder that updates, packages, and proofs never touch
- A read-only local dashboard (`node system/dashboard/serve.mjs`)
- Safer updates: smaller short-lived staging, a rollback stack, restores
  confirmed by checkpoint hashes, updates that work on a personalized Home
  Base, and a repair for an update left unfinished by a 1.0.x updater
- A Capability Doctor that checks Codex, Claude Code, and Grok Build
  separately
- Complete command output when an assistant reads it through a pipe
- Tracked-files-only packaging, private-skill linking, and a maintainer
  privacy scan
- Node.js 20 or later for everything a user runs

## Added in 1.2.0

- Dashboard themes: ask your assistant to restyle the local dashboard, or
  start from a preset (`precise`, `soft`, `night`, `calm`); your theme lives
  in `instance/dashboard/` and hard-to-read colours keep the default
- An optional locked online copy of the dashboard on your own Vercel account
  (`node system/dashboard/publish.mjs`): a harmless placeholder goes up first,
  and your copy is built only after `--check-locked` confirms that Vercel asks
  for a sign-in on every address

## Release boundary

The official `v1.2.0` GitHub release is the current immutable distribution
source. The `v1.0.0`, `v1.0.1`, and `v1.1.0` tags and releases remain
unchanged as history.
Skills and local workflows never grant account access or permission for an
external action. Connections, sends, publishing, spending, deployment, and
future updates still require their own explicit review and approval.
