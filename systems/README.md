# Systems

Each chosen use case gets its own folder:

```text
systems/<system-name>/
├── BLUEPRINT.md
├── HARNESS.md
├── CONNECTIONS.md
├── BUILD-MODE.md
├── INTERFACE.md
├── DEPLOYMENT.md
├── PROOF.md
└── LEARNINGS.md
```

Discovery and a blueprint do not authorize outside action. `BUILD-MODE.md`
records the exact opt-in threshold, scope, worst case, stop conditions, and
undo for external execution.
