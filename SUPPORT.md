# Support

EspoAI Home Base is free, community-supported software. Support is best effort;
there is no SLA and no promised response or repair time.

## Supported releases

- **Latest stable:** supported for documentation corrections, safe-update
  defects, and reproducible product issues on a best-effort basis.
- **Preview or release candidate:** useful for testing, but may change or be
  withdrawn without migration support.
- **Older releases:** preserved as immutable history. Upgrade to the latest
  stable before requesting a fix.

## Supported environments

- **Primary:** current Codex Desktop on a currently supported macOS release.
- **Preview:** Claude Code adapter until a named live keeper run is recorded.
- **Community/unverified:** other operating systems, agents, forks, and custom
  toolchains. Unverified does not mean known-broken.

Start with `system/inspect-runtime.mjs`, `system/validate.mjs`, and the relevant
guide. Use the structured bug form for a sanitized reproduction. Once GitHub
Discussions is separately enabled, use it for questions and workflow ideas.

Never post credentials, client data, proprietary repository contents, private
prompts, or unredacted diagnostic output. Use [`SECURITY.md`](./SECURITY.md)
for sensitive reports.

Personalized setup, account recovery, connector/vendor support, and managed
implementation are separate services and are not included in community support.
